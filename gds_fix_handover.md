## 5. Tokenisation map

Rule of thumb for the default lane (`gdsTheme`): GDS emits `--gds-bg-*`, `--gds-text-*`, `--gds-border-card`, `--gds-overlay-*` and `--gds-motion-*` from `styles.css`, and feeds Mantine's `--mantine-spacing-*`, `--mantine-radius-*` and shadows from the density, shape and elevation axes. `--gds-space-*`, `--gds-radius-*`, `--gds-elevation-*` and `--gds-control-height-*` are not defined at `:root` in this lane, so use component props and `--mantine-*` variables until [#765](https://github.com/sovereignsquad/general-design-system/issues/765) ships. Targets that exist only in a newer release or under a preset say so in the row. Prefer the prop or component target; use the variable only where no component fits.
